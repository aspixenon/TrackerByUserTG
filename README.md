## 🚀 О проекте

**TrackerByUserTG** — это скрипт на базе библиотеки Telethon, который позволяет:
* В реальном времени следить за появлением пользователя в сети.
* Логировать точное время входа и выхода.
* Работать с несколькими сессиями через API Telegram.

> **Важно:** Бот предназначен для использования в образовательных целях или для личного мониторинга. Уважайте приватность других пользователей!

Для создания бота использовались следующие инструменты:

## ⚙️ Установка и запуск

Следуйте этим шагам, чтобы развернуть проект локально:

### 1. Подготовка API
Для работы вам понадобятся `API_ID` и `API_HASH`. Получить их можно на сайте [my.telegram.org](https://my.telegram.org).

### 2. Клонирование репозитория

git clone [https://github.com/aspixenon/TrackerByUserTG.git](https://github.com/aspixenon/TrackerByUserTG.git)
cd TrackerByUserTG
3. Настройка окружения
Создайте файл .env (или отредактируйте переменные в коде) и добавьте свои данные:

Фрагмент кода

API_ID=ваш_id
API_HASH=ваш_hash
4. Установка зависимостей

pip install -r requirements.txt
5. Запуск

python main.py
📂 Структура проекта
main.py — точка входа, инициализация клиента и обработка событий.

config.py — настройки и конфигурационные данные.

sessions/ — папка для хранения файлов сессий .session.

💡 Как это работает?
Бот использует систему событий UserUpdate. Как только статус отслеживаемого контакта меняется, срабатывает триггер:

Проверяется текущее состояние (Online/Offline).

Время события записывается в консоль или текстовый файл.

Система ожидает следующего обновления без блокировки основного потока.

📊 Telegram User Tracker Bot

Профессиональный инструмент на базе Pyrogram для мониторинга статуса активности пользователей в Telegram. Бот автоматически отслеживает, когда выбранные пользователи заходят в сеть и выходят из неё, сохраняя историю для анализа.

🚀 Основные возможности

Мониторинг в реальном времени: Мгновенное обнаружение смены статуса (Online/Offline).

Логирование: Запись всех перемещений в текстовый файл или базу данных.

Обход ограничений: Работает через UserBot API, что позволяет видеть статусы эффективнее обычных ботов.

Простая настройка: Конфигурация через переменные окружения или файл.

🛠 Технологический стек

Язык: Python 3.8+

Библиотека: Pyrogram

API: Telegram API (MTProto)

📋 Инструкция по установке

1. Подготовка API ключей

Для работы бота вам понадобятся API ID и API HASH.

Перейдите на my.telegram.org.

Войдите в систему и выберите "API development tools".

Создайте новое приложение и сохраните ваши данные.

2. Клонирование репозитория

git clone [https://github.com/aspixenon/TrackerByUserTG.git](https://github.com/aspixenon/TrackerByUserTG.git)
cd TrackerByUserTG


3. Установка зависимостей

Рекомендуется использовать виртуальное окружение:

python -m venv venv
source venv/bin/activate  # Для Linux/macOS
# или
venv\Scripts\activate     # Для Windows

pip install -r requirements.txt


4. Настройка

Создайте файл .env в корневой папке или отредактируйте конфиг:

API_ID=ваш_api_id
API_HASH=ваш_api_hash


🎮 Запуск

Запустите основной скрипт:

python main.py


При первом запуске Pyrogram попросит ввести номер телефона и код подтверждения от Telegram для создания сессии (.session файл).

📖 Как это работает

Инициализация: Бот авторизуется как клиент (UserBot).

Подписка: Скрипт проверяет список контактов или указанных ID.

Обработка событий: Используется обработчик UserStatusEvent. Как только статус пользователя меняется, бот получает уведомление от серверов Telegram.

Вывод: Данные выводятся в консоль и записываются в файл логов с указанием времени.
